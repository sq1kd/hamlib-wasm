Connect a radio over USB (or through a USB-to-serial adapter), pick its model
and press **Grant port & connect**. The browser asks which port to use; the page
never sees ports you do not grant. Once connected, the setup gives way to the
radio's front panel; **Disconnect** brings it back.

Tick **Show library calls** to see what the panel does under the hood. The log
also lets you choose, before connecting, which of two ways drives the **same**
rig and the same Hamlib module:

- **Rig** - `rig.setMode(mode)`, `rig.setPassband('narrow')` and a
  `useRigState` poll that reads one snapshot per tick;
- **Raw** - `rig.raw`, the underlying `RawRig`: `getFrequency()`, `getMode()` and
  `getPtt()` polled by hand, and `setMode(mode, width)` with an explicit width
  from `passbandNormal()`.

The log shows exactly which library calls each one makes.

:::note[Requirements]
A desktop Chromium-based browser or Firefox 151+, and a radio. Without Web
Serial the demo still loads and lists the model catalogue, but cannot connect.
The demo writes to the radio only when you press a control - including PTT, so
mind your antenna.
:::

The demo loads with this page only: it fetches the Hamlib WebAssembly module
and its loader, a few megabytes, which no other page of this site does. If your
browser asks to save data, it waits for a click instead.
